# Code of conduct

Liyab adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

In short: be respectful and constructive, welcome people of every background and level of experience, criticize
ideas rather than people, and assume good intent. Harassment, insults, and personal or political attacks are not
acceptable in any project space (issues, pull requests, discussions) or when representing the project elsewhere.

## Reporting

Report unacceptable behaviour privately to the maintainer through GitHub
([@andrei-borcea](https://github.com/andrei-borcea)). Reports are handled confidentially. The maintainer may remove,
edit or reject contributions, and temporarily or permanently ban anyone whose behaviour is not aligned with this
code of conduct, following the Covenant's enforcement guidelines.
